# A.5-PRD-v1

**Stage:** assemble PRD v1 — five sections (Company + Value Proposition, Target User, Jobs to Be Done,
Features, Prototype). About 45–90 minutes.

**Skill:** `prd` — say "write my PRD". It pre-fills Sections 1–3 from your value proposition, persona and
prioritized jobs, then walks Features and Prototype with you.

**Inputs:** value proposition, persona, prioritized jobs, company ground truth.

**You do by hand:** fill in `A.5-PRD-v1-Template.md` (the skill guides each decision but never fills it
for you). The Prototype section is your commitment: the prototype form, the hypothesis, the flow, the
test (who, how many, how) and what counts as a pass. A "feature" is anything the customer experiences —
a capability, a spec or attribute, or an asset or experience — so this works for software, physical
products, CPG, fashion, marketing and services alike.

**Where things land:** your template stays here; the agent's derived `PRD-v1.md` goes to
`2_Outputs/.agents/A.5-PRD-v1/`. A Word version is not shipped; ask your agent to export the Markdown to
.docx if you prefer Word.

**Next:** `prototype-kit` ("set up my prototype").
