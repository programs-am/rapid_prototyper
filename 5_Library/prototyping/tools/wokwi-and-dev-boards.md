# Wokwi and Dev Boards

Prototype works-like electronics with the Wokwi browser simulator, then move to real boards such as Arduino, ESP32 or Raspberry Pi.

- **Pricing:** Wokwi has a free tier at time of writing; Arduino IDE is free software; boards are low cost. Check current pricing.
- **Pricing note:** Prices and limits change often; last reviewed Jun 2026 — check the vendor's site before relying on it.
- **Best for:** A founder with a device idea (sensors, lights, motors, connected gadget) who wants to test the logic before building hardware.
- **Safety:** Never prototype anything on mains voltage (wall power) without a qualified person. Lithium batteries can overheat or catch fire; use protected modules, charge them as directed and never leave them unattended. Stay with low-voltage USB power for early prototypes.

**5-Step Quickstart**
1. Go to wokwi.com and start a new project for Arduino or ESP32
2. Ask an AI assistant to write starter code for your idea and the parts list (sensor, button, LED, display)
3. Add parts in the diagram, wire them and run the simulation to test the logic without buying anything
4. When it works, buy a dev board and the same parts, load the code with the Arduino IDE or your board's tools, and build it on a breadboard
5. Record a short video of it working, and note what would need a custom PCB or enclosure next

**Watch First:** Search YouTube for "Wokwi Arduino ESP32 tutorial"
