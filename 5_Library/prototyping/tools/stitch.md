# Stitch

Google's AI-powered UI design tool — describe any screen in plain English and get a polished, production-ready UI in seconds. No design experience needed.

- **Pricing:** Free. 550 generations/month (350 Standard via Gemini 2.5 Flash + 200 Pro via Gemini 2.5 Pro). No credit card required.
- **Pricing note:** Prices and limits change often; last reviewed Jun 2026 — check the vendor's site before relying on it.
- **Best for:** A founder who wants quick, good-looking screen designs to test an app or site idea before any build.

**5-Step Quickstart**
1. Go to stitch.withgoogle.com and sign in with any Google account
2. Click 'New design' and describe the UI you want — e.g. 'A mobile home screen for tracking water quality with a dashboard and alert system'
3. Stitch generates high-fidelity UI screens — review the result
4. Iterate by chatting: 'Add a navigation bar', 'Make the color scheme blue and white', 'Add a settings page'
5. Export to Figma format or React code — or click 'Prototype' to stitch screens into a clickable flow to share

**Watch First:** Search YouTube for "Google Stitch tutorial"
