# Claude (Chat and Claude Code for Mockups)

Use Claude to turn a description into HTML pages, clickable mockups, simple SVG graphics, copy and slide-style decks you can open in any browser.

- **Pricing:** Claude has a free tier at time of writing; heavier use needs a paid plan. Check current pricing.
- **Pricing note:** Prices and limits change often; last reviewed Jun 2026 — check the vendor's site before relying on it.
- **Best for:** Any founder who wants a quick landing page, clickable flow, pitch copy or a rough vector sketch without learning a design tool.
- **Limits:** Claude writes code and rough vector or HTML visuals. It does not make photorealistic product photos; use an image tool or mockup generator for those. Form submissions and logins in a generated page will not work without a backend.

**5-Step Quickstart**
1. Open claude.ai and start a new chat (or run `claude` in a project folder if you use Claude Code)
2. Describe the artifact: who it is for, the sections or screens you need, tone, and any real copy — e.g. 'A one-page landing site for a reusable lunch bag with a hero, three benefits and an email signup'
3. Ask for a single self-contained HTML file (or an artifact, if your plan shows them) so you can preview it right in the chat
4. Iterate in plain language: 'Make the hero shorter', 'Add a pricing section', 'Redraw the logo as simple SVG shapes'
5. Download or copy the HTML, open it in a browser to share, or paste it into a site builder; for decks, ask for one HTML page per slide and print to PDF
