# AI Text-to-3D Tools

Category guide to AI tools such as Meshy and Tripo that turn a text prompt or reference image into a 3D model.

- **Pricing:** Has a free tier at time of writing; check current pricing. Often limited credits on free plans.
- **Pricing note:** Prices and limits change often; last reviewed Jun 2026 — check the vendor's site before relying on it.
- **Best for:** A founder who wants a looks-like concept model, a visual for a deck, or a quick shape exploration.
- **Limits:** Output is not engineering-ready. Expect wrong dimensions, thin or broken geometry and messy surfaces. Use for looks only. Check each tool's commercial-use terms.

**5-Step Quickstart**
1. Choose a tool (for example Meshy or Tripo) and sign up
2. Use a clear reference image or a prompt describing shape, material and style; a clean single-angle image on a plain background works best
3. Generate a few options and pick the closest
4. Download as GLB, OBJ or STL, view it in a 3D viewer, and render it into images for a deck or landing page
5. If you need a physical part, rebuild it in CAD (Fusion, Onshape, OpenSCAD) using the AI model as a visual guide
