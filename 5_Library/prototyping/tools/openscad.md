# OpenSCAD

Free, open-source CAD where you describe a 3D shape in a short script; AI chat assistants can write the scripts for you.

- **Pricing:** Free and open source at time of writing; check the project site.
- **Pricing note:** Prices and limits change often; last reviewed Jun 2026 — check the vendor's site before relying on it.
- **Best for:** A founder who wants simple, parametric parts (boxes, brackets, holders, caps) and is happy to ask an AI to write the code.
- **Note:** Works well for simple, geometric parts. Organic shapes and complex assemblies are difficult. Always check generated dimensions against a real part before printing.

**5-Step Quickstart**
1. Download OpenSCAD from openscad.org and install it
2. Ask Claude or another chat assistant to write a script: give dimensions in mm, wall thickness, holes and tolerances, e.g. 'a 60 x 40 x 20 mm enclosure with 2 mm walls and a snap-fit lid'
3. Paste the script into OpenSCAD and press Preview (F5), then Render (F6)
4. Change the variables at the top of the script (or ask the assistant to) until it fits your real components
5. Export as STL and send it to a 3D printer or print service
